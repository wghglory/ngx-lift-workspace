noSpaceAllowed ensures that a text control contains no whitespace characters. onlyAsciiCharsAllowed ensures that a control contains only ASCII characters in the range \u0020 - \u007E.

Examples

Identifier & ASCII Restrictions

Test inputs with spaces or non-ASCII characters (e.g., emojis or unicode letters):

Must not contain spaces @if (form.controls.identifier.errors?.['noSpaceAllowed']) { Spaces are not allowed in identifiers } Only standard ASCII characters allowed @if (form.controls.asciiOnly.errors?.['onlyAsciiCharsAllowed']) { Non-ASCII characters or unicode symbols are not permitted }

Returns

Returns {noSpaceAllowed: true} or {onlyAsciiCharsAllowed: true} on violation, or null if valid.
