dns1123SubdomainValidator and k8sNameValidator enforce RFC 1123 subdomain and Kubernetes resource naming standards. They check for lowercase alphanumerics, hyphens, boundary characters, and maximum length constraints (253 characters for subdomains, 63 characters for Kubernetes resource names).

Examples

Kubernetes Cluster & Resource Names

Test valid and invalid Kubernetes identifiers:

Lowercase alphanumerics, '-', and '.' up to 253 chars @if (form.controls.subdomain.errors?.['dns1123Subdomain']) { Must consist of lowercase letters, numbers, or '-', and start/end with an alphanumeric character. } @if (form.controls.subdomain.errors?.['dns1123SubdomainLength']) { DNS subdomain cannot exceed 253 characters. } Lowercase alphanumerics and '-' up to 63 chars (no dots) @if (form.controls.k8sResource.errors?.['k8sName']) { Must be a valid Kubernetes name (lowercase alphanumeric characters or '-', max 63 characters, starting and ending with an alphanumeric character). }

Returns

Returns {dns1123Subdomain: true}, {dns1123SubdomainLength: true}, or {k8sName: true} on violation, or null if valid.
