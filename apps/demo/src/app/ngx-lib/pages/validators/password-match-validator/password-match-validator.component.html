passwordMatchValidator is a cross-field form group validator that compares two password controls (e.g., password and confirmPassword). When they differ, it sets the passwordMismatch: true error directly on the confirmation control, making error display intuitive and standardized.

Examples

Password Confirmation Form

Enter matching or non-matching passwords:

Enter your new password @if (form.controls.password.errors?.['required']) { Password is required } Repeat password exactly @if (form.controls.confirmPassword.errors?.['required']) { Confirmation is required } @if (form.controls.confirmPassword.errors?.['passwordMismatch']) { Passwords do not match }

API Reference

passwordMatchValidator

Validates matching values across two form controls within a FormGroup.

Signature

Returns

A validator function returning {passwordMismatch: true} on the confirmation control or null if both values match.
