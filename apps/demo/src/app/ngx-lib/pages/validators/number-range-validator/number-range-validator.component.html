numberRangeValidator validates that the minimum numeric value is less than or equal to the maximum numeric value within a FormGroup. If min > max, it flags both controls with minGreaterThanMax: true.

Examples

Min & Max Range Boundaries

Adjust the values below so that Minimum > Maximum (e.g. min: 10, max: 5):

Lower bound @if (form.controls.min.errors?.['minGreaterThanMax']) { Minimum cannot be greater than Maximum } Upper bound @if (form.controls.max.errors?.['minGreaterThanMax']) { Maximum cannot be less than Minimum }

API Reference

numberRangeValidator

FormGroup validator checking that min ≤ max.

Signature

Returns

A validator function returning {minGreaterThanMax: true} if min > max, or null if valid.
