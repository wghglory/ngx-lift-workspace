fileExtensionValidator validates that a filename string ends with one of the allowed extensions (e.g., ['crt', 'pem', 'key'] or ['.png', '.jpg']). Matching is case-insensitive.

Examples

Certificate File Upload Name

Test allowed certificate extensions (.crt, .pem, .key) versus invalid extensions (.exe, .txt):

Allowed extensions: .crt, .pem, .key @if (form.controls.filename.errors?.['invalidFileExtension']; as err) { Invalid file extension. Allowed extensions: {{ err.allowedExtensions.join(', ') }} }

API Reference

fileExtensionValidator

Factory creating a validator checking if a filename ends with one of the specified extensions.

Signature

Returns

Returns {invalidFileExtension: {allowedExtensions}} if the extension does not match, or null if valid.
