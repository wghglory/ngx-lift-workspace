composeValidators sequentially executes an array of validation rules and returns immediately upon the first failing validator with a single configured errorKey mapping to the failed rule's message. This short-circuits further evaluation and cleanly displays a single targeted error message at a time.

Examples

Sequential Username Validation

Short-circuits validation: checks min length → max length → no spaces.

Between 3 and 15 characters, no spaces @if (form.controls.username.errors?.['required']) { Username is required } @if (form.controls.username.errors?.['usernameError']; as errorMsg) { {{ errorMsg }} }

API Reference

composeValidators

Composes multiple validation rules and stops at the first failure.

Signature

Returns

A validator function returning { [errorKey]: message } for the first failing rule or null if all pass.
