jsonValidator verifies that a text input contains syntactically valid JSON. Empty or whitespace-only values are ignored (pair with Validators.required if mandatory).

Examples

Configuration Editor

Edit the JSON below or introduce syntax errors (e.g., trailing comma or missing quote):

Enter valid JSON object or array @if (form.controls.config.errors?.['invalidJson']) { Invalid JSON format. Please verify quotation marks and commas. }

API Reference

jsonValidator

Angular validator verifying valid JSON syntax via JSON.parse().

Signature

Returns

Returns {invalidJson: true} on syntax parse error, or null if valid.
