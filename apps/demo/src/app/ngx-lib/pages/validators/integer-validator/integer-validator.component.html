integerValidator ensures that a control value represents a whole number (integer), rejecting floating point numbers, decimals, and non-numeric inputs.

Examples

Pod Replicas Count

Enter whole integers vs decimals (e.g., 2 vs 2.5):

Whole number of replica pods @if (form.controls.replicas.errors?.['integer']) { Value must be an integer (no decimals allowed) }

API Reference

integerValidator

Angular validator checking if the value is an integer via Number.isInteger().

Signature

Returns

Returns {integer: true} if the input is not a whole number, or null if valid.
