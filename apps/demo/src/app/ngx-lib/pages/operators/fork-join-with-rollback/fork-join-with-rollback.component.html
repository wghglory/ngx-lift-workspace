forkJoinWithRollback executes an array or dictionary of asynchronous creation tasks in parallel. If any task fails, all newly created resources (tagged with isNew: true) that succeeded before or during the failure are automatically rolled back and deleted via the provided deleteHandler before the error is surfaced.
