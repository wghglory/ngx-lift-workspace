ngx-lift/testing provides lightweight, zero-boilerplate testing harnesses for Angular signals, routing, and side effects. Because it is published under its own secondary entry point, testing utilities are never bundled into production builds.

Install or import testing utilities directly via ngx-lift/testing in your test specs.

Testing Utilities

1. Synchronous Signal Effects with flushEffects()

Angular's effect() runs asynchronously as microtasks or during change detection. flushEffects() force-flushes the internal EffectScheduler synchronously without requiring fakeAsync, tick(), or boilerplate fixture.detectChanges().

2. Reactive Route Mock with ActivatedRouteMock

Mocks Angular's ActivatedRoute with reactive paramMap, params, queryParamMap, queryParams, and data. Includes setParams() and setQueryParams() helper methods to test live navigation changes mid-test.

3. Mock Router with RouterMock

A drop-in mock for Angular's Router that provides full spies for navigate(), navigateByUrl(), an active events Subject that emits NavigationEnd, and url trackers.
