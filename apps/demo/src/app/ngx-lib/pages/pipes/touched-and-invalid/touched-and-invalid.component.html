touchedAndInvalid is an impure template pipe that determines whether a form control has been touched by the user and is in an invalid state. It can check general invalidity or filter for a specific validation error key.

Examples

Interactive Form Control Validation

Focus the email input and click outside (blur) without typing anything to mark it as touched, or type an invalid email address:

Enter your corporate email address @if (form.controls.email | touchedAndInvalid: 'required') { Email address is required. } @if (form.controls.email | touchedAndInvalid: 'email') { Please provide a valid email format (e.g. user@example.com). }
Control Status: {{ form.controls.email.status }} Touched: {{ form.controls.email.touched }}

API Reference

Pipe Signature

Parameters

  • control: AbstractControl | null | undefined — The form control to inspect.
  • errorKey?: string — Optional specific error key (e.g., 'required').
