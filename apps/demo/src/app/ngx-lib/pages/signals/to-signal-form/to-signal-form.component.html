Architecture & API Guide

1. toSignalForm: The Unified Facade

Provides a single, strongly-typed entry point for all reactive form signals, control diagnostics, declarative bindings, and backend payload preparation. Controls under sf.controls are authentic FormControl instances with attached signals.

2. bindIf: Dynamic Control Presence with Memory

Mounts or unmounts a group of related controls (such as database credentials) together based on a reactive condition. Detached controls are automatically excluded from validation and backend payloads, and their input is preserved across switches when preserveValue: true is configured.

3. bindDisabled: Declarative Enable/Disable

Binds a control's enabled/disabled state directly to a boolean signal or reactive getter function (() => boolean). It supports strongly-typed control keys, direct sf.controls.<name> enhanced controls, and AbstractControl instances. Defaults to emitEvent: true to ensure reactive status signals update synchronously, and supports optional reset-on-disable with a strongly-typed resetValue.

4. sf.submitValue: Clean Submission Value Preparation

Solves the tension between form.value (which drops disabled controls) and form.getRawValue() (which dumps UI-only fields like confirmPassword). sf.submitValue() provides a continuous reactive signal that is always sanitized and ready for submission or resourceAsync.

5. Async Capability Gating (computedAsync + bindIf)

In cloud and enterprise applications, available form fields often depend on regional capabilities or feature flags resolved asynchronously from API endpoints. computedAsync derives a reactive Signal<boolean> from the selected region and engine, which passes directly into sf.bindIf to mount or unmount capability controls on the fly.

6. Cascading Updates: Signal Watch vs RxJS valueChanges (Angular 22 Style)

When a form control's change triggers cascading updates in another control (e.g. resetting available versions when the database engine changes), you can use the traditional RxJS valueChanges.pipe(takeUntilDestroyed()) pattern or the signal-first sf.controls.<name>.watch() / sf.watch() utility. watch operates inside an Angular effect() with automatic untracked isolation, preventing NG0600 signal write errors while eliminating manual subscription teardown.
