The AutocompleteComponent provides an overlay-driven dropdown input built on top of Angular CDK Overlay and Clarity Design System. It supports real-time text filtering, keyboard navigation (ArrowUp, ArrowDown, Enter, Escape), blur and click-outside dismissal, and two-way integration with Angular Reactive Forms (ControlValueAccessor).
