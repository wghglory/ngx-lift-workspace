The ConfirmModalComponent (<cll-confirm-modal>) is a turnkey confirmation dialog with integrated loading states, inline error feedback, customizable buttons, and optional toast notifications on completion.

Examples

Example 1: Destructive Action (Delete Confirmation)

Demonstrates a dangerous deletion workflow with a danger button and success toast:

Last Action Status: {{ lastActionMessage() }}

Are you sure you want to permanently delete cluster db-production-01? All data and backups will be lost.

Example 2: General Action Confirmation & Inline Error Handling

Demonstrates standard confirmation with a primary button and simulates an async failure to showcase inline error display:

Are you ready to promote version v2.4.0 to the production cluster?

This operation will simulate an API error to show how inline alerts are rendered inside the modal.
