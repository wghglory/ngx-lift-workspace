<cll-key-value-grid> and <cll-key-value-item> provide an elegant, responsive metadata display layout. It automatically adapts columns across viewports (1 column on mobile up to 4 columns on wide screens) or accepts an explicit column count.

Examples

Example 1: Responsive Metadata Grid

Resize your browser window to see the grid transition seamlessly between 1, 2, 3, and 4 columns. Items support both direct inputs and projected content like badges and icons.

Example 2: Fixed Two-Column Layout

Set [columns]="2" to enforce a structured 2-column configuration regardless of container width.

API Reference

cll-key-value-grid

Property Type Default Description
gap string '1.5rem' CSS gap between grid cells.
columns number | 'auto' 'auto' Fixed number of columns or responsive 'auto'.

cll-key-value-item

Property Type Default Description
key string - Metadata label text.
value string | number - Metadata value content.
