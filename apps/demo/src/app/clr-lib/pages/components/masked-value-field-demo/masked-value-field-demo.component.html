<cll-masked-value-field> is a presentational component that masks sensitive values (passwords, tokens, credentials, connection strings) by default. Users can toggle visibility using an accessible show/hide button and optionally copy the value directly to the clipboard.

API Reference

Property Type Default Description
value string | number | null | undefined - The sensitive value to mask.
placeholder string '●●●●●●●●●●' Placeholder shown when masked.
emptyPlaceholder string '-' String displayed when value is empty or null.
copyable boolean false Whether to render an integrated copy button.
copyTooltip string '' Tooltip for copy button when copyable is true.
