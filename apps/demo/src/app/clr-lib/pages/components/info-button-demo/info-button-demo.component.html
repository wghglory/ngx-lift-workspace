<cll-info-button> renders a stylized action or navigation button. When disabled, it can display an informative icon and hover tooltip explaining why the operation is unavailable to the user.

Examples

Example 1: Action Trigger

Use the (clicked) event output to execute arbitrary component callbacks.

Clicks: {{ actionCount() }}

Example 2: Router Link Navigation

Provide a link input (with optional queryParams and state) to automatically navigate via Angular Router.

Example 3: Disabled with Reason Tooltip

When [disabled]="true" and a tooltipText is provided, an info icon appears and hovering the button shows the explanatory tooltip.

API Reference

Property Type Default Description
text string required Button label.
tooltipText string '' Explanatory tooltip displayed when disabled.
tooltipPosition TooltipPosition 'tooltip-right' Tooltip placement relative to button.
tooltipWidth number 240 Tooltip box width in pixels.
link string | string[] | null null Router navigation path or segment array.
queryParams Record<string, unknown> | null null Router query parameters.
disabled boolean false Whether the button is disabled.
clicked OutputEmitterRef<void> - Emitted on click when link is not set.
