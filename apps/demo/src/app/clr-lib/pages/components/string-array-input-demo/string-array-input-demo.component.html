<cll-string-array-input> is a reactive form control that transforms comma-delimited user input into a native TypeScript string[]. It implements ControlValueAccessor, supports custom delimiters, whitespace trimming, deduplication, and full validation synchronization.

Examples

Example 1: Basic Reactive Form Binding

Type tags separated by commas. Notice how the underlying form state dynamically updates to an array of trimmed strings.

Form Model Value: 
{{ demoForm.get('tags')?.value | json }}

Example 2: Automatic Deduplication

Set [unique]="true" to automatically eliminate duplicates from the parsed array.

Form Model Value: 
{{ demoForm.get('domains')?.value | json }}

API Reference

Property Type Default Description
label string '' Input label text.
placeholder string '' Input placeholder.
helperText string 'Separate values with commas' Helper text displayed below input.
delimiter string ',' Delimiter character used to separate values.
trim boolean true Whether to trim whitespace around values.
unique boolean false Whether to eliminate duplicate values.
