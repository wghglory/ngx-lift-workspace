<cll-copy-to-clipboard> provides a standardized, accessible copy-to-clipboard button using Clarity Design System icons and tooltips. It integrates with Angular CDK Clipboard and displays visual loading and success states automatically.

Examples

Example 1: Basic Inline Usage

Attach to tokens, URLs, connection strings, or table cells. Hovering shows a helpful tooltip, and clicking copies the value into the user's system clipboard with instant visual confirmation.

Example 2: With Text Label

Provide a text input to display a clear call-to-action button alongside the icon.

Example 3: Disabled State

When disabled, the component switches its icon to an info indicator and displays the disabledTooltip.

API Reference

Property Type Default Description
value string | number required The value copied to clipboard.
text string '' Optional text label next to the icon.
tooltip string 'Copy to clipboard' Tooltip shown when hovering over enabled button.
tooltipPosition string 'right' Clarity tooltip placement.
disabled boolean false Whether the button is disabled.
disabledTooltip string '' Tooltip displayed when disabled.
copied OutputEmitterRef<string> - Event emitted when value is successfully copied.
