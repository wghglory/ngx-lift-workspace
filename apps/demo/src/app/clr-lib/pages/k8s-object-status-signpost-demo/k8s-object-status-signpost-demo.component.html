The K8sObjectStatusSignpostComponent (<cll-k8s-object-status-signpost>) extracts and displays the overall health reason from a set of Kubernetes conditions, dynamically applying semantic Clarity status colors (success, error, warning, info), with an interactive signpost to inspect raw condition payloads.
