# Create a library design specification

Follow the shared [lift-design skill](../../../.agents/skills/lift-design/SKILL.md), including the canonical workflow,
spec template and form contract it links. Write specs under `docs/design/` and update an existing canonical spec when
its behavior changes. Keep repository documentation in English.

The previous `design/<feature>.md` and overview-pair convention is superseded by this shared workflow. Keep existing
documents as source evidence; create a separate overview only when requested or when it serves a concrete audience.
