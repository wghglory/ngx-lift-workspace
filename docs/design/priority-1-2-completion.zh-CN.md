## 加载与发布验证

Demo 先同步转义源码，再由代码展示组件异步加载 highlight.js；复制时仅解码一次，保留源码中的实体、泛型与运算符。证书示例在交互后加载，并把键盘焦点转交给实际触发按钮。文件读取页异步加载证书校验；PENDING 或加载失败时禁止提交。库的同步证书解析、校验接口保持原样。

生产构建检查遍历静态依赖图，确保 highlight.js、node-forge 不进入初始包，也不进入两个证书相关页面的静态依赖。独立 tarball 消费者严格验证 peer 依赖、类型与运行时导入。发布工作流默认 dry
run；即使选择一个包，也构建两个包供消费者验证。dry run 不需要 npm 凭据，不产生版本提交或 tag，也不实际发布。

## 国际化

11 种 Demo 语言统一要求覆盖全部英文键，包括 API 描述。CI 检查缺失、多余、空值、占位符漂移、翻译残留标记与被翻译的策略枚举。API 表格在语言切换和字典加载后重新计算。Clarity 原生文案覆盖上游全部键；回归测试能发现上游新增文案。语言切换先恢复上游和英语基线，再合并基础语言与精确区域覆盖，避免残留上一种语言。

翻译由 AI 辅助生成，并审查了 API 标识、并发语义、重试安全和占位符。未取得独立母语人工签核；这项语言验收不能用键数齐全代替。

## 所有权、时钟与诊断

`provideIdleDetectionService()` 隔离功能注入器；`[scoped]="true"` 隔离单个组件。共享实例共享超时配置，不同策略应隔离。
`watch()` 返回幂等释放函数；最后一个托管所有者退出才清理计时器。显式 `startWatching()`
的所有者继续持有计时器，直到清理或销毁。组件先应用配置，再启动首个计时器。

Query
diagnostics 返回独立 key 副本，pending 总数包含仍在运行的旧请求。面板每秒刷新，销毁后停止。真实组件测试覆盖同 key 的不同 stale/poll/GC 配置、卸载与作用域隔离；共享 key 继续采用已声明的保守合并策略。

证书 Clock 支持返回 Date 或时间戳的回调，也支持 signal。每次状态计算只采样一次。自定义 Clock 由调用方推进；默认浏览器 Clock 每分钟推进并随注入器销毁清理。

## computedAsync

实现和类型均保持不变。错误被当作值的类型债务应在独立 major 或新命名的可选 API 中处理。Result 包装会要求现有赋值、属性访问、模板和 previous-value 回调先解包；默认抛错则改变运行时行为。本 PR 不引入这些变化。
