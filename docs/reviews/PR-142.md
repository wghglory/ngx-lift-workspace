## Publication decision

**Local code quality: approved by this review. Immediate publication: not yet.**

The corrected nullable `isEmpty`/`isNotEmpty` predicates, initial undefined typing of `combineFrom`, and explicit null
return typing of `mergeFrom` can break consumer compilation. Preserve these correctness fixes and ship a migration
guide; under semantic versioning, recommend a **major ngx-lift release**. `clr-lift` has additive functionality and
fixes, so a **minor release** is appropriate based on the reviewed changes. A tentative independent plan is
`ngx-lift@22.0.0` and `clr-lift@21.1.0`, subject to checking version availability. This does not imply raising Angular
peer requirements.

Before publishing:

- Confirm GitHub checks and the maintainer approval on the final pushed PR commit, then merge to the release base.
- Apply the chosen independent version bumps and generate changelogs with the migration notes.
- Verify target versions are unused and run the existing authenticated publish workflow.

Source manifests remain `ngx-lift@21.1.1` and `clr-lift@21.0.0`. Registry lookup did not complete in this environment,
so availability of proposed versions was not verified. GitHub CLI lacks github.com authentication; public web access
retrieved the PR description, and SSH supports fetching/pushing. Formal GitHub review approval and final remote CI
status were not asserted or submitted. Publishing credentials were not tested.
