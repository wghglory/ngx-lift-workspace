# PR #142: Final code review and release assessment

Reviewed `origin/main...HEAD` on `fix/async-resource-lifecycle-dsm-trial`, with base
`765833621b6f837e9877eaa7d3e8a3e2c4ef7819`. The standards and specification reviews ran independently.

## Standards

Three findings were addressed:

- **P2, pagination compatibility:** legacy `{retryConfig: false, limit: 50}` parameters were discarded. Mixed parameter
  objects now remain HTTP parameters. A lone `{retryConfig: false}` remains the documented opt-out; nest it under
  `initialParams` when it should be sent as an HTTP parameter.
- New public query API JSDoc now includes usage examples.
- Published README links now use repository URLs instead of referring outside the package.

## Specification

Three correctness findings were reproduced and fixed:

- **P1, reentrant query notification:** removing a query during notification allowed a later observer to receive removed
  private data again. Nested refresh could also overwrite a newer loading snapshot. A publication revision stops older
  notification batches; detached observers are skipped.
- **P2, nullable emptiness typing:** `isNotEmpty` still narrowed an empty array away in the false branch. Collection
  checks now return boolean, matching the migration contract. Compiler assertions cover genuinely nullable function
  parameters in both branches.
- **P2, cyclic equality:** comparisons of self-cycles and two-node cycles depended on argument order. Ancestor
  correspondence is tracked in both directions, preserving symmetry.

Inaccurate design examples were also corrected: `maxEntries`, actual mutation methods and root client behavior,
`resourceAsync` concurrency modes, captured loader parameters, and fixed fallback retry delays.

## Release assessment

Local code verification does not authorize or constitute npm publication. The PR contains breaking type/lifecycle
changes and must be described and versioned accordingly; source manifests remain `ngx-lift@21.1.1` and
`clr-lift@21.0.0`. The changelog now has an Unreleased section and the migration guide documents affected consumers.

Release remains conditional on:

- Successful remote checks for the final pushed commit and the normal merge/release review.
- Choosing unused independent release versions, including a breaking-change-compatible version for `ngx-lift`.
- A completed dependency audit and advisory triage. The configured mirror returns HTTP 405; the official npm audit timed
  out. GitHub reports 60 open default-branch Dependabot alerts (25 high, 31 medium, 4 low), which are not verified
  counts for this branch or the published packages.
- Using the authenticated publish workflow after merging and versioning. `NPM_TOKEN` exists as a repository secret; its
  validity was not tested or exposed.
