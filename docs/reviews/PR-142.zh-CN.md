## Spec 与回归修复

- 初始同步 observer 回调内移除 query 或销毁 client 后，旧 entry 仍会启动 loader。回调后重新检查 attachment，避免旧 scope 请求。
- 初始 snapshot 回调移除 query 时，Observable
  adapter 尚未取得 handle，导致订阅无法结束。取得 handle 后再次检查并 complete。

  生命周期更新借用内容，保留调用方 attachment 与销毁所有权。
- Kubernetes 分页将名为 `initialParams` / `retryConfig`
  的旧标量 HTTP 参数误判为 options。按值形状区分，回归测试覆盖首请求与后续页参数。
- demo 改版后，浏览器测试引用已移除 wrapper/class、未限定 table，或使用旧 tooltip 文案。按当前 example/preview 定位并更新断言。

以上五类回归均已修复。新增共享 query/mutation 用法说明与迁移说明，并确认 `mergeFrom()`

## 是否可以发布新版本

**本地代码审查通过；尚不能直接发布。** `isEmpty` / `isNotEmpty` 的 nullability 谓词修正、`combineFrom` 初始 `undefined`
类型与 `mergeFrom` 的 `null` 类型修正可能影响下游编译，应遵循 semver 发布 ngx-lift **major**
版本，并携带迁移说明。clr-lift 的新增功能与修复适合 **minor** 版本。可考虑独立版本
`ngx-lift@22.0.0`、`clr-lift@21.1.0`，但需先验证版本未被使用；这不代表提高 Angular peer 要求。

发布前剩余工作：确认最终推送 commit 的 GitHub
CI 与维护者 approval，合并到发布基线，更新独立版本和 changelog，验证版本可用性，再运行已有认证发布流程。当前 manifest 仍为
`ngx-lift@21.1.1`、`clr-lift@21.0.0`。registry 查询在本环境未完成，未验证版本可用性。GitHub
CLI 缺少 github.com 登录；公开网页可读取 PR，SSH 可推送。本报告不宣称已取得 GitHub 正式 approval，也未测试 npm 发布凭据。
