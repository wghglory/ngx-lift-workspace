# PR #142：最终代码评审与发布判断

完整英文记录见 [PR-142.md](PR-142.md)。评审基线为 `origin/main`，standards 与 specification 分别评审。

## 已修复问题

- **Standards：3 项。** 修复 pagination 的同名参数被静默丢弃；补充 query API 使用示例；将 npm
  README 中失效的相对文档链接改为仓库链接。
- **Specification：3 项。** QueryClient 通过发布序号阻止同步重入后投递旧快照，避免已删除的数据重新出现；修复
  `isNotEmpty` 对 nullable 集合的不安全分支缩窄；双向追踪祖先对应关系，使 cyclic `isEqual` 保持对称。
- 纠正文档中的不存在 API、错误并发选项、未捕获的 loader 参数与指数退避描述。

## 验证

`ngx-lift` 698、`clr-lift` 223、demo
170 个测试均通过。源码与测试类型检查、lint、生产构建通过。28 个 Chromium 测试在本轮最终 library 修复前已通过，之后变更由完整单元测试与构建验证。两个包的 npm
pack dry run 通过。

## 是否可以发布

本地代码验证通过，不等于 npm 发布已经准备完成。PR 有 breaking changes，已补充 Unreleased
changelog 与 migration，但尚未选择独立新版本；当前源码仍是 `ngx-lift@21.1.1`、`clr-lift@21.0.0`。

还需确认最终 push 的远程 CI、完成依赖审计与告警分流、选择未被使用的版本并合并。镜像审计接口返回 HTTP
405，官方 npm 审计超时；GitHub 默认分支有 60 项未关闭告警，其中 25 high，这不是当前分支或发布包的已验证漏洞数量。
`NPM_TOKEN` secret 存在，但未验证凭据有效性，也未执行发布。
