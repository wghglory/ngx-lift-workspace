# Scope of design work

For a new public API or a material contract change, follow the
[component development workflow](../../docs/design/component-development.md) and
[lift-design skill](../skills/lift-design/SKILL.md). Reuse existing approval for its stated scope.

For routine fixes, refactors, tests and documentation within an approved contract, use the relevant existing spec and
proceed within the user's request. Record changed behavior and evidence without starting a new design-approval cycle.

For library/demo UI, retain the
[accessibility and localization contract](../../docs/guides/accessibility-and-localization.md).
